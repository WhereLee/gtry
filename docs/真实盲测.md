# 真实问题盲测

模板语料上的 recall@5 0.9975 只能证明链路正确，不能证明真实客服问题也能命中。
上线前建议用 50–100 条真实问题做一次盲测。

## 1. 标注

1. 打开 `http://127.0.0.1:8091/`（或云端 `/helpdesk/`），切到“知识库”；
2. 用“测试检索”输入真实问题，确认最应该回答的页面；
3. 记录到 `docs/真实盲测模板.csv`：

```csv
question,pageId
"我买的耳机订单满 110 元，退货需要注意什么？","<页面 UUID>"
```

页面 UUID 可以在知识库页面的详情里看到，或调用
`GET /api/wiki/pages?spaceId=...&limit=200` 获取。

## 2. 导入

用该租户的管理员账号导入（会替换该租户已有的 REAL 问题）：

```powershell
powershell -File tools\import-eval.ps1 -Tenant acme -Csv docs\真实盲测模板.csv -Replace
```

## 3. 评测

平台管理员触发：

```powershell
Invoke-RestMethod -Method Post -Uri "http://127.0.0.1:8091/api/admin/eval?sample=200&kind=REAL" -Headers $ph
Invoke-RestMethod -Uri http://127.0.0.1:8091/api/admin/eval/status -Headers $ph
```

指标与同分布/盲测一致：recall@5、MRR@10、nDCG@10，按页面判定。

## 4. 判读

- recall@5 低于 0.8：优先检查知识库是否缺少对应页面，而不是先调模型；
- 命中但 MRR 低：正确页面排在 2–5 位，通常是切块或重排问题；
- 引用为空但答案正确：模型没有按 `[1][2]` 标注，检查 prompt 或换模型。
